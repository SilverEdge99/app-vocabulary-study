# Vocab · 本地离线背单词（第一版）

FastAPI + SQLite（WAL），**只监听 127.0.0.1**，单机自用、断网可用。前端是一个 `index.html`，
无框架、无 CDN、无外部字体，图标全部内联 SVG。默写数据全部存 SQLite，**不使用 localStorage / IndexedDB**。

```
vocab-app/
  main.py            后端：建表 / 判分 / 会话 / 统计 / 导入导出 / 静态托管
  index.html         前端：单文件，深/浅主题
  requirements.txt   依赖（版本已锁定）
  pylibs/            已内置的依赖（main.py 自动加进 sys.path，pip 坏掉也能跑）
  setup_deps.py      离线重装依赖用（走 PyPI JSON，不需要 pip）
  sample_vocab.csv   40 词示例，方便先试
  vocab.db           首次启动自动生成（不入版本库）
```

---

## 1. 启动

最省事：双击 `启动.bat`。命令行等价写法：

```powershell
cd vocab-app
python main.py
```

默认会在 1 秒后自动打开 `http://127.0.0.1:8017`。参数：

```powershell
python main.py --no-browser        # 不自动开浏览器
python main.py --port 8020         # 换端口
python main.py --db D:\data\vocab.db   # 换数据库位置
python main.py --selftest          # 只跑自检（判分 + 调度 + WAL），不启动服务
```

> 端口被上一个窗口占着时会**自动顺延**（8017 被占就用 8018……并打印实际地址），不会启动失败。

**依赖说明**

- `pylibs/` 里已经放好了全部依赖，**不用装任何东西**，直接 `python main.py` 就能跑。
- 里面同时带了 Python **3.11 和 3.12**（Windows x64）的 `pydantic_core` 二进制，这两个版本的 Python 都能直接用。
- 想自己装到全局/虚拟环境：`pip install -r requirements.txt`，然后把 `pylibs/` 删掉即可
  （`main.py` 只有在 `pylibs/` 存在时才把它加进 `sys.path`）。
- 如果 pip 在这个环境里不好用，用离线脚本：`python setup_deps.py`（走 PyPI JSON 直连下载 wheel 并解包到 `pylibs/`，会按当前解释器挑 wheel）。

> Python **3.13** 及以上需要重装依赖：删掉 `pylibs/` 后跑 `python setup_deps.py`，或 `pip install -r requirements.txt`。
> 非 Windows 或 32 位环境同理（`pydantic_core` 是平台相关二进制）。

**安全**

- 服务只绑定 `127.0.0.1`，局域网访问不到；不要改成 `0.0.0.0`。
- 所有接口校验 `Origin` / `Referer`，非本机来源直接 403（防本机浏览器里其他网页 CSRF）。

## 2. 五分钟上手

1. **词书 → 新建词书**，起个名字（例如「雅思核心词」）。
2. **导入导出 → 选择文件**，传 `sample_vocab.csv`（`word,meaning` 两列，带不带表头都行；UTF-8 / GBK 自动识别）。
3. **词书**页里给这本词书设「每日新词」，比如 20。
4. **背诵**页：选「看中文写英文」，范围「新词」，题量 20 → **开始默写**。
   - 输入答案按 `Enter` 提交；**答错会停在原地让你重试**（不会直接跳到下一题，也不显示答案）
   - 想不出来时：**直接空着提交**，或按 `Esc` / 点「看答案」→ 才会显示正确答案（这一题记作答错）
   - 答对（或看答案）后自动进入下一题：答对 1.2 秒、看答案 2.4 秒
5. 一组做完出**报告**：总题数 / 答对数 / 正确率 / 用时 / 错题列表。
6. **复习**页：到期复习、错题复习、**昨日回顾**、整本复习，点一下直接开一组。
   - 昨日回顾 = 把昨天背过的词**全部再过一遍**（无视到期时间，最多 200 词），适合当天没背干净的情况
7. **统计**页：今日/本周/本月的新词、复习、正确率、连续打卡、完成率，加近 7 天柱状图。

每张词书卡片底部有「重命名」「删除词书」；删除会**级联删掉该词书下的单词和复习记录**，
确认框里会显示待删词数，建议先导出 JSON 备份。单词表每行的按钮：
`用法`、`设为掌握 / 取消掌握`、`改释义`、`重置`、`删`。

### 用法 / 例句

- **默写时无论答对答错**，结果条下面都会显示这个词的「词组搭配」和「例句」；这个词还没填过时，
  会显示「现在补充」按钮，点开就能写。
- 也可以从「词书」页每行的 `用法` 按钮编辑。词组的每行一条、例句每行一条，
  保存后 `用法 ✓` 表示已经有内容。
- CSV 支持第 3、4、5 列：`word,meaning,phrases,examples,pos`，多条用 `|` 分隔。
  导入时对**已存在**的词只补空的用法，不覆盖你手写的内容。

### 每日记录

「记录」页按本地日期列出每一天：学了几个词、其中新词几个、正确率。
点某一天，右边就是那天的单词清单（按词去重），带「全对 / 错 N 次」「新词」标记和最后作答时间，
有用法/例句的词会顺带显示前两行。范围可切近 14 / 30 / 90 天。

快捷键：`Enter` 提交 · `Esc` 看答案 · `Alt+D` 切深浅色（弹窗里 `Ctrl+Enter` 保存）。

### 单词发音（朗读）

用的是**系统自带语音**（浏览器 `speechSynthesis`，Windows 的 Microsoft 英文语音），
不联网、不装包、不会把单词发到任何服务器。

出现「🔊」的地方点一下就朗读：

- **今日计划**列表：单词旁边有 🔊；**直接点单词本身**也会读
- **当日记忆**、**记录**页的单词行：点单词就能读
- **词书**词表：每个单词右边有 🔊
- **默写**：模式 B（看英文写中文）题面下方有「🔊 朗读单词」，快捷键 `Ctrl + 空格`
- **答题结果**的「用法 / 例句」标题旁也有 🔊

没声音的话：系统缺英文语音包 —— `设置 → 时间和语言 → 语言 → 添加语言` 装一个英语，
装完刷新页面。控制台也会提示「这个浏览器/系统没有可用的英文语音」。

### 今日计划（今天要背的全部单词）

词书卡片上的「今日计划」按钮，打开就是**今天这一整组**：

- 上面一行：`待学 12（到期 5 · 新词 7）· 今天已学 8 · 每日新词上限 20（已用 8）`
- 中间进度条：今天已学 / 今天总量
- 列表**全部展开**，每条都标明状态：
  - `待学 · 到期`（该复习了）
  - `待学 · 新词`（今天的额度内、还没开始）
  - `已对` / `错 N 次`（今天已经背过的，按词去重）
- 右上「开始这一组」直接把**待学的那些词**拉进默写（按这个顺序出题，不重复）
- **点任意单词**（不是点 🔊）→ 弹出该词的详情卡：
  - 单词 + **词性**（如 `n. / v.`）+ 🔊 朗读
  - 中文释义
  - **词组 / 搭配**
  - **例句**
  - 底部：「✨ AI 生成」（本地 Ollama 现生成并入库）、「编辑用法」（手改，含词性输入框）

词性从哪来：CSV 第 5 列 → AI 生成 → 手动填写；都没有时，程序会从释义里的
`n.` / `v.` / `adj.` 前缀自动推断一个。

和「当日记忆」的区别：当日记忆只列**已经背过**的；今日计划把**还没学的**也列出来，
所以能看清"今天一共多少、还剩多少"。

### 当日记忆 + 对话文章生成

每张**词书卡片**底部有一个「当日记忆」按钮：

1. 点开先看**今天背过的词**（按词去重，带「全对 / 错 N 次」「新词」标记）
2. 下面就是「对话文章生成」：
   - **类型**：场景故事 / 日常对话
   - **长度**：100 / 200 / 300 快选，或自己填（50–800 words）
   - 点生成，几秒后出一段**英文正文**，每段后面跟「中文：」开头的整段翻译
3. 生成结果可以「复制全文」；当天生成过的会列在下面，点一下随时回看

> 需要 Ollama 可用（同下面的 AI 说明）。生成的内容会存进 `daily_writings` 表（按词书+日期留档）。
> 实测：200 words 约 6 秒（模型写不够会**自动再扩写一次**，一般能到 85%–90% 目标词数）。

### 本地 AI（可选，用 Ollama 生成词组和例句）

需要本机装了 [Ollama](https://ollama.com) 并至少拉过一个模型，例如：

```powershell
ollama pull qwen2.5:7b      # 约 4.7GB，8GB 显存够用；更省显存可用 qwen2.5:3b
```

装好模型后，程序会自动发现（`/api/ai/status`）。三种用法：

1. **默写时**：结果里没有用法/例句的词，会多一个 `✨ AI 生成` 按钮 —— 生成后直接存库并展示。
2. **词书页**：每行 `用法` → 弹窗里有 `✨ AI 生成`，生成只是**填进输入框**，你看过再点保存。
3. **导入导出页**：`AI 补齐当前词书缺失的用法` —— 只补没有用法的词，后台跑、有进度条。
   7B 模型在 RTX 5060 上约 **2–3 秒/词**。

模型在界面上可切换（下拉框），默认存在 `app_settings.ai_model`。

> 没装 Ollama / 没启动 / 没模型时，这些按钮会自动隐藏或置灰，**背诵、复习、统计完全不受影响**。
> AI 调用只发往 `127.0.0.1:11434`，出不了本机；想换地址可用环境变量 `OLLAMA_BASE`。

## 3. 数据与备份

- 全部数据在 `vocab.db`（WAL 模式下还会有 `vocab.db-wal` / `vocab.db-shm`）。
- **备份请用「导出 JSON」**，不要直接拷 `vocab.db`（可能拷到半截 WAL）。导出前后端会自动 `wal_checkpoint(TRUNCATE)`。
- 想清空重来：停掉服务，删 `vocab.db`、`vocab.db-wal`、`vocab.db-shm`，重新启动。
- CSV 导出是给表格看的（含 FSRS 字段）；JSON 导出带全部字段，适合换机迁移。
- `word_books` / `words` / `review_logs` 三张表**完全按约定的 DDL，一列没改**。
  另有两张辅助表：`app_settings`（主题、每日计划等键值）、`word_details`（词组/例句，按 `word_id` 主键，
  外键级联删除）。

## 4. 接口一览

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/health` | 健康检查，返回 journal_mode |
| GET/POST | `/api/books` | 词书列表（含词数/掌握/错题/到期）/ 新建 |
| PUT/DELETE | `/api/books/{id}` | 改名 / 删除（级联删词） |
| PUT | `/api/books/{id}/plan` | 设每日新词 |
| GET | `/api/books/{id}/words` | 词表，支持 `page/size/q/filter=all\|due\|error\|mastered` |
| POST/PUT/DELETE | `/api/words[/{id}]` | 加词 / 改释义·标记掌握·重置进度 / 删词 |
| POST | `/api/session/start` | 开一组：`{book_id, mode:A\|B, scope:new\|due\|error\|book, limit}` |
| GET | `/api/session/{id}` | 续接会话（刷新页面不丢） |
| POST | `/api/session/answer` | 提交一题（幂等，重复提交只记一次） |
| POST | `/api/session/finish` | 结束并出报告 |
| GET | `/api/stats?book_id=&range=day\|week\|month` | 统计 + 近 7 天图表 |
| GET/PUT | `/api/words/{id}/detail` | 读取 / 保存「词组 + 例句」 |
| GET | `/api/history/days?book_id=&limit=` | 按天汇总（词数/作答/正确率/新词数） |
| GET | `/api/history/day?book_id=&date=YYYY-MM-DD` | 某天的单词清单 |
| GET | `/api/history/today?book_id=` | 今天（本地时区）背过的词 = 当日记忆 |
| GET | `/api/plan/today?book_id=` | 今日计划：待学（到期+新词）+ 今天已学 |
| POST | `/api/session/start` | 开一组：`{book_id, mode, scope, limit, ids?}`（`ids` 用于「开始这一组」） |
| POST | `/api/ai/story` | 用当天单词生成故事/对话（`style`、`length`） |
| GET | `/api/ai/story?book_id=&day=` | 当天生成过的短文列表 |
| GET | `/api/ai/story/{id}` | 回看某篇短文 |
| GET | `/api/ai/status` | Ollama 是否可用、有哪些模型 |
| POST | `/api/ai/usage` | 为单个词生成词组/例句（`save=false` 只预览） |
| POST | `/api/ai/fill_book` | 批量补齐（返回 `job_id`） |
| GET | `/api/ai/jobs/{id}` | 批量任务进度 |
| POST | `/api/import/csv` | multipart：`book_id` + `file`（可带 phrases/examples 两列） |
| GET | `/api/export?book_id=&format=json\|csv` | 导出（含用法字段） |
| GET/PUT | `/api/settings` | 主题、自动跳下一题等 |

判分规则（后端做，前端不放宽）：

- **英文**：忽略大小写/首尾标点/连字符；支持 `apple; apples` 这类多答案。
- **中文**：全角转半角、去标点；库里释义按 `;；,，、/` 拆义项，答出其中任一义项即算对。

## 7. 常见问题

**端口被占用**：`python main.py --port 8020`。

**导入后中文乱码**：Excel 另存 CSV 时选「CSV UTF-8」；本程序已兼容 GBK，仍有问题请用 UTF-8 存。

**中文判分总判错**：库里释义可能是长句。建议一条释义只放 2–4 个义项，用 `；` 分隔，
例如 `放弃；抛弃`。程序会按义项匹配，答出任一义项即对。

**答错的词复习时消失了**：错题在「复习 → 错题」里，答对且间隔推进到 7 天以上会自动清除错题标记。

**想换主题不生效**：主题存在 `app_settings` 表，`Alt+D` 切换后会写回；若浏览器拦截了请求，刷新一次即可。
